# Development Roadmap (7 Phases)
## CodePulse AI — Socratic Coding & Retention Coach

| Phase | Milestone | Focus Area | Status |
|---|---|---|---|
| **Phase 1** | **Frontend Prototype & Monaco Workspace** | React, Vite, Tailwind CSS, Authentication UI (Demo), Student Dashboard, Problem Catalog, Monaco Python Editor, Socratic Hint UI, Retention Analytics, Vercel SPA Config | **Completed** |
| **Phase 2** | **Backend & PostgreSQL Authentication** | Express REST API, PostgreSQL schema, Prisma/pg client, bcrypt hashing, JWT cookie session tokens, Protected routes | Reserved for Prompt 2 |
| **Phase 3** | **Gemini AI Socratic Coaching Service** | Google Gemini API integration, Socratic prompt engineering with zero-spoiler safeguards, streaming SSE hint delivery | Planned |
| **Phase 4** | **Sandboxed Code Execution Engine** | Python 3 execution sandbox, timeout limits, test suite evaluation, memory and runtime profiling | Planned |
| **Phase 5** | **Spaced Repetition & Retention Engine** | Ebbinghaus forgetting curve modeling, retention scoring, adaptive review notifications | Planned |
| **Phase 6** | **End-to-End Testing & Hardening** | Vitest, Playwright E2E tests, rate limiting, error monitoring, audit logging | Planned |
| **Phase 7** | **Production Deployment & Launch** | Vercel (Frontend), Railway / Cloud Run (Backend), Managed PostgreSQL (Supabase / Neon), Custom Domain & CI/CD | Planned |
